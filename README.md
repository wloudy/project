# 🛠 Технологии

## 🌐 Основной стек:
- **HTML5** - Семантическая разметка
- **CSS3** - Grid, Flexbox, анимации, 3D трансформации
- **JavaScript (ES6+)** - Интерактивность, анимации

## 🎨 Стили и анимации:
- **CSS Grid & Flexbox** - Современные системы верстки
- **CSS Custom Properties** - Переменные для тем
- **3D Transforms** - Эффекты перспективы
- **Gradients & Shadows** - Сложные градиенты

## 📚 Библиотеки и ресурсы:
- **Font Awesome 6** - Иконки
- **Google Fonts** - Шрифты
- **CSS3 Keyframes** - Кастомные анимации

## 🎭 Особенности реализации:
- **Parallax Effects** - Эффекты параллакса
- **Typewriter Effect** - Эффект печатной машинки
- **Interactive Timeline** - Интерактивная хронология
- **Modal Windows** - Модальные окна
- **Responsive Design** - Адаптивный дизайн
- **Local Storage** - Сохранение настроек

# 🎨 Особенности

## 1. Атмосферный дизайн 🎭
- Эстетика XIX века с элементами старинной бумаги
- Цветовая палитра чернил и пергамента
- Анимированные фоны с параллаксом

## 2. Интерактивные элементы 💫
- Анимированная навигация с эффектами
- 3D карточки романов с поворотом
- Интерактивная хронология с маркерами
- Генератор цитат со случайным подбором

## 3. Иммерсивные эффекты ✨
- Печатная машинка для заголовков
- Летающие элементы (персонажи, книги)
- Чернильные кляксы с анимацией
- Параллакс-слои для глубины

## 4. Функциональность 🛡️
- Ночной/дневной режим чтения
- Копирование цитат в буфер
- Адаптивный дизайн для всех устройств
- Плавные переходы между разделами

## 5. Образовательный контент 📚
- Подробная биография писателя
- Описание основных романов с ссылками
- Философские концепции творчества
- Хронология жизни и творчества
